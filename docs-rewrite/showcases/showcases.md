# Showcases

TScratch is suited to small interactive projects that benefit from simple,
Scratch-like primitives and a typed codebase.

## Project ideas

- platformers built from `Rectangle`, `Circle`, and collision checks;
- drawing tools using `Pen` and `CustomPolygon`;
- menus made from `Text` and `Button` sprites;
- multiplayer games using `Multiplayer` and `RoomManager`;
- procedural scenes using `Perlin1D` or `Perlin2D`;
- simple 3D experiments using `Object3D` and the built-in renderers.

A showcase is easiest to maintain when its scenes, sprite setup, and game loop
are kept in separate modules. See the getting-started and scenes sections for
that structure.
